SUBJECT: Possessed Text. Typographic reference for a matched word that shudders as if
possessed. This sheet is not a character; it shows letterform treatments for a placeholder word.

PALETTE: ink #17121F, possessed red #C93B2B, red shadow #7E1F18, ghost tint #BDB4D6,
bone highlight #F2EEF8, background panels none (use only the flat magenta ground).

CANONICAL STATES (top row, four stacked samples of the word "SPIRIT" in a bold geometric sans,
same size):
1. Rest: clean letters in ink.
2. Jitter: every letter nudged a few pixels in different directions and rotated up to 4 degrees,
   with a duplicate offset copy in red behind it.
3. Warp: letters stretched tall, centre letters bulging, slight wave along the baseline.
4. Split: the word cut by one jagged horizontal slice with the top half shifted right.

CONSTRUCTION PARTS (middle row): a single letter "S" shown with its red echo copy at three
offsets (left, right, down); a jagged slice line; a small cluster of five tiny sparks.

PROOFS (bottom row): the word "SPIRIT" in a gothic blackletter treatment, flat ink, for a
possible swap state.

AVOID: gore, blood drips, eyes in the letters, realistic distortion textures, anything
unreadable.
